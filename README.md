# junkcode

Freddy's junk drawer. Small tools, half-finished experiments and one-off scripts
that were useful enough to keep but not important enough to get a repo of their own.

It lives here for reference and as a backup. Nothing is actively maintained, and
things may be broken, abandoned or rewritten without notice. If something here is
useful to you, take it.

## What's in here

| folder | what |
|---|---|
| [`lyrebird/`](lyrebird/) | Offline speech-to-text dictation with a custom vocabulary and optional local grammar cleanup. |
| [`tarstamp/`](tarstamp/) | Shell function that makes a timestamped `.tar` snapshot of a file or directory before a risky change. |
| [`usage-tracing/`](usage-tracing/) | Claude Code skill for tracing token use and cost of agents in a project. |

Each folder is self-contained and has its own README with setup and usage.

## Ground rules

- **No support.** Issues and PRs may sit unanswered.
- **No stability.** Folders get added, moved and deleted as needed.
- **Check the licence per folder.** Some projects ship their own `LICENSE`; where
  there isn't one, ask before reusing anything.
